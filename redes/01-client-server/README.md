# Lab 01 — Client/Server

## Objetivo

Compreender o modelo Client/Server e como aplicações clientes e servidoras se comunicam para solicitar e fornecer dados. As aplicações podem estar na mesma máquina ou em máquinas diferentes.

## O que é Client/Server?

É um modelo de comunicação em que uma aplicação cliente solicita dados ou serviços a uma aplicação servidora, que processa a solicitação e fornece uma resposta.

## Como funciona?

Uma aplicação cliente envia uma solicitação para uma aplicação servidora. O servidor recebe e processa essa solicitação e, quando aplicável, envia uma resposta contendo os dados ou o resultado solicitado.

## Exemplo prático

Um navegador pode atuar como cliente ao solicitar uma página web a um servidor.

Se o servidor precisar buscar informações em um banco de dados, ele passa a atuar como cliente em relação ao servidor do banco de dados.

Dessa forma, uma mesma aplicação pode atuar como servidor em uma comunicação e como cliente em outra, dependendo da relação analisada.

## O que eu aprendi?

Aprendi que os papéis de cliente e servidor são definidos de acordo com a comunicação. Uma aplicação pode ser cliente em uma relação e servidor em outra, e esse modelo é utilizado em diversas aplicações e serviços de rede.
